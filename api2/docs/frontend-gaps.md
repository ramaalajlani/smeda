# فجوات Frontend معروفة

## Admin — مكتمل

- **admin-users.php:** إنشاء، تعديل، تفعيل/تعطيل، تغيير كلمة مرور، مزامنة أدوار/صلاحيات، فلاتر
- **admin-roles.php:** عرض، إنشاء، تعديل، حذف، ربط صلاحيات
- **admin-permissions.php:** عرض مجمّع حسب module
- **admin-activity-logs.php:** سجل نشاط مع فلاتر وتفاصيل
